What it is Reading a paper Writing it back The tablet, over the network Working the queue Every command

Every command

paperpen --help prints this list; paperpen <command> --help prints one.

The shelf

paperpen add <repo-or-pdf>Register a paper: find the main file, build it once.
paperpen listWhat is registered.
paperpen shelfThe shelf in the terminal, and where the browser one is.
paperpen about <paper>Kind, brief, delivery, archived, the agent and its runner. --agent, --runner claude|codex.
paperpen whereWhich registry and caches are in force.
paperpen check <repo>Whether a repository is ready to be added.

Reading and rounds

paperpen serveThe shelf, the reader, the editor. --port, --host, --lan, --no-tls, --qr, --light, --debug (loopback only).
paperpen build <paper>latexmk with SyncTeX, into the cache.
paperpen rounds <paper>Every round, and how each one stands.
paperpen finish <paper>Close the open round and deliver it. --as repo|pdf|folder, --no-commit.
paperpen notes <paper>Every note, and whether it is closed.

The queue

paperpen queueEvery open note. --json, --paper, --tag, --unclassified, --older-than, --limit.
paperpen nextWhat to do first. --json, --all, --fast.
paperpen classify <paper> <id> <TAG>SCIENCE, LANGUAGE, QUESTION or TODO.
paperpen resolve <paper> <id> <done|rejected|open> ["what was done"]Close a note, with what was decided.

The agent reading first

paperpen agent <paper>The agent answers the newest round, Claude Code unless --runner codex. --print, --background, --status, --stop.
paperpen review <paper>The agent reads the paper and writes notes of its own, each with its fix, into review/<date>-claude/, or -codex/. --focus, --max, --runner, --background, --print.
paperpen suggest <paper> --tag T --note "..."One such note, placed from the text it fixes: --file, --old, --new (or --edits JSON), or --at for a remark with no fix.
paperpen approve <paper> <id> [<fix>]Put its fix in the working tree and close it done.
paperpen reject <paper> <id>...Close them as rejected. --why, which the next run reads.

Versions

paperpen versions <paper>The log, and which of it is built. -n.
paperpen versions <paper> --build <ref>The paper as it was at that commit.
paperpen versions <paper> --diff <ref>latexdiff, compiled.
paperpen versions <paper> --source <ref>What git diff says about the .tex.
paperpen versions <paper> --forgetThrow the version builds away.

The network, and the state

paperpen lanChoose how the reader on the network lets people in: password and app code, password, or no login. --no-login, --clear.
paperpen tlsA self-signed certificate, and how to trust it. --renew.
paperpen qrThe address as a QR code. --url, --light.
paperpen bundleThe state as one .tar.gz. --ink, -o.
paperpen record <paper>Refresh review/paperpen.json in the paper's repository.
paperpen adopt <repo-or-url>Put a paper back on the shelf from the record its repository carries.
paperpen syncPull the papers' repositories, re-read the rounds.

Environment

PAPERPEN_HOMEWhere the registry lives.
PAPERPEN_CACHEBuilds and rendered pages.
PAPERPEN_DATAThe rounds.
PAPERPEN_LATEXDIFFThe latexdiff command, for a manuscript that needs its own flags.
